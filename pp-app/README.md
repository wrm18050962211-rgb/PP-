# Still / PP 生活方式影像平台 MVP

移动端优先的 Web App 初始化版本。

## 产品方向

PP 项目的 App 主品牌暂定为：

```text
Still
```

中国区副标题：

```text
留住此刻的样子
```

Still 不是普通约拍、陪拍或写真工具，而是面向 C 端的一线城市生活方式影像服务平台。它要把用户在某个城市、场景、阶段和状态里的样子认真记录下来。

PP 的核心闭环仍然是：发现作品 -> 咨询摄影师 -> 报价 -> 下单 -> 平台内沟通 -> 拍摄交付 -> 双方共同编辑作品 -> 可选择同步到主页。

后续产品会在“正式拍摄前”加入妆造能力，分两步演进：

1. 化妆：引入“化妆师”身份。化妆师和摄影师一样需要提交资料并经过管理员后台审核，审核通过后才能对外展示和接单。创作者在找摄影师之前，可以先按地点、时间、风格和预算筛选化妆师，完成化妆预约后再进入摄影师预约流程。
2. 穿衣：等 LT 项目可用后再接入。PP 根据拍摄地点沉淀该地点常见穿搭、风格和购买线索，用户可以把目标地点和风格带入 LT，在对应背景下试穿同类衣服，再决定是否购买或带到拍摄现场。

MVP 阶段不把化妆师和穿衣能力写进主流程代码，只在产品和数据设计中预留：

- 化妆师是独立服务身份，不等同摄影师。
- 化妆服务需要后台审核、服务范围、档期、报价、订单、聊天和风控。
- 摄影预约前可以串联化妆预约，但两个订单要保持独立，避免结算和纠纷混在一起。
- 穿衣能力先作为 LT 外部能力接入，PP 只负责提供地点、风格、作品参考和购买/试穿入口。

## 单赛道判断

中国区目前没有看到一个强重合、已经成为头部的垂直 App。相邻产品和替代流程包括：

- 麻豆约拍、去拍、Starry、咔咔约拍等：摄影预约或约拍工具，偏交易撮合。
- 图虫、500px 中国版等：摄影师社区、作品展示、学习和变现，不是普通用户拍摄服务闭环。
- 海马体、天真蓝：线下标准化照相馆品牌，强在证件照、形象照和棚拍体验。
- 妙鸭、星绘、美图秀秀、醒图：AI 写真、修图和人像美化，满足“想要好看照片”的部分需求。
- 小红书：用户找摄影师、看客片、找地点、学姿势、找妆造的重要入口。

Still 的机会不是做另一个泛约拍黄页，而是把分散流程变得更省心、更标准、更可信：

```text
风格灵感 -> 摄影师/地点/时间/价格 -> 拍前准备 -> 拍摄交付 -> 作品沉淀
```

## MVP 切口

Still 早期建议从“一线城市生活方式外景拍摄标准化套餐”切入，而不是泛摄影服务平台。

优先场景：

- 城市旅行照；
- 周末外景人像；
- 生日/纪念日；
- 小红书出片套餐；
- 个人形象生活照；
- 毕业/情侣/朋友照。

早期最重要的不是复杂功能，而是服务标准：

- 摄影师审核；
- 样片真实性；
- 风格标签；
- 场景路线模板；
- 固定套餐；
- 价格透明；
- 拍前 checklist；
- 平台内沟通和订单留痕；
- 交付时限；
- 修图范围；
- 取消、退款和纠纷规则；
- 用户隐私和线下安全机制。

## 竞品启发

海外 Snappr 的启发是：摄影服务平台要规模化，必须把摄影师审核、拍摄套餐、交付范围、风格 brief、平台沟通和后期编辑流程标准化。

Still 不应一开始做 Snappr 式大而全企业视觉内容平台。更适合先做 C 端的“普通人的城市生活方式影像体验”。等 C 端供给、作品、摄影师网络和交付标准形成规模后，再考虑 B 端视觉内容业务，例如商家视觉内容、店铺/品牌拍摄、达人内容拍摄、商品场景图和本地生活商家视觉更新。

## 与 Vibe / LT 的关系

LT 项目的 App 主品牌暂定为 Vibe，定位是“找到适合生活的样子”。

两个 App 的长期关系是：

```text
Vibe：找到样子
Still：留住样子
```

Vibe 负责帮助用户找到适合自己生活、衣橱、场景和状态的样子；Still 负责把这个样子放进真实世界，通过摄影、地点、姿态、光线和作品交付沉淀为影像记忆。

两者未来可以组合成完整宇宙，但 Still 单独看也成立：它的单赛道机会是从拍照灵感到影像交付。

## 技术栈

- React + TypeScript
- Vite
- React Router
- Tailwind CSS
- lucide-react 图标

## 目录说明

- `src/features/user`：用户端页面：首页图片流、帖子详情、订单、消息、我的
- `src/features/companion`：陪拍者端工作台
- `src/features/admin`：运营后台 MVP
- `src/components`：跨页面复用组件
- `src/data`：MVP 阶段模拟数据
- `src/layouts`：应用外壳与底部导航
