## 待处理问题

### IOS-UI-001：注册页顶部辅助文字对比度偏低

- 状态：待修复
- 优先级：P2
- 影响：首次进入时，“首次使用 Still”和说明文字在黑色背景上不够清晰，弱光环境和低亮度下可读性较差。
- 复现步骤：
  1. 清除本地登录状态或首次安装 App。
  2. 打开 Client 注册页。
  3. 在无键盘的首屏观察标题上方提示和标题下方说明。
- 当前表现：主标题清晰，但 eyebrow 和说明文字使用较暗灰色。
- 期望表现：辅助文字保持层级差异，同时达到稳定可读的对比度。
- 代码定位：`pp-app/src/features/auth/AuthPages.tsx` 中的 `AuthFrame` 和注册页样式。
- 建议修复：提高深色背景下辅助文字的亮度，并检查浅色/深色主题是否共用错误颜色。
- 验证标准：iPhone 15 Pro Max 真机在常规亮度和低亮度下均可轻松读取，且不削弱主标题层级。

### IOS-PERF-001：注册后首次进入发现首页耗时过长

- 状态：已改善，待首次安装冷路径复测
- 优先级：P1
- 影响：注册成功后等待首页出现的时间明显偏长，削弱首次使用信心，用户可能误以为操作失败或 App 卡住。
- 复现步骤：
  1. 首次安装或清除本地账号状态。
  2. 使用 Client 身份完成 Mock 注册。
  3. 从点击“注册账号”开始计时，直到发现首页首批可交互内容稳定显示。
- 当前表现：优化后注册跳转本身已很快，但首次安装且无图片缓存时，远程封面在约 15 秒连续采样内仍未显示，首页长时间呈现黑色内容块。
- 期望表现：注册提交后立即给出明确反馈，尽快显示可交互骨架或缓存内容，首批真实内容渐进加载。
- 代码定位：`pp-app/src/features/user/HomeFeed.tsx`、注册后的路由切换、首页数据服务和图片加载链路。
- 初步定位：
  1. `HomeFeed` 使用路由级延迟加载，但全局 `Suspense` fallback 为 `null`，模块等待期间表现为空白。
  2. 注册页未提前加载约 49 KB 的 `HomeFeed` 代码块。
  3. 首页多张 `PhotoCard` 分别重复生成完整 Mock feed 和统计虚拟点赞数据，造成不必要的同步计算。
  4. 首轮真机包配置了 `http://127.0.0.1:8787`；在 iPhone 上该地址指向手机本身，应改为纯 Mock 或可从局域网访问的 Mac 地址。
- 2026-07-24 第一轮处理：
  1. 注册页显示期间预载 `HomeFeed` 代码块。
  2. 将空白路由 fallback 替换为稳定的发现页骨架。
  3. 缓存静态 Mock feed 的派生结果。
  4. 将首页卡片点赞数从逐卡重复计算改为一次批量计算。
  5. 下一版真机包使用无 API 地址的开发 Mock 配置，排除无效本机请求。
- 2026-07-24 第二轮处理：
  1. 真实图片加载前立即显示本地内嵌占位，避免网络请求悬挂时出现整页黑块。
  2. 仅当前频道首批卡片使用高加载优先级，降低相邻频道对首屏带宽的竞争。
  3. 将双列 Unsplash 封面请求从 900 像素缩小到 640 像素、横幅缩小到 960 像素。
  4. 注册页停留期间预取发现页前 4 张封面，真实图片加载后再渐进替换占位。
- 验证记录：
  1. 移动端生产构建通过；生产保护检查通过；仓库全量 ESLint 仍被 4 个本次修改前已存在的问题拦截。
  2. 优化版覆盖安装并保留账号、图片缓存后冷启动，0.5 秒采样时发现首页和首屏图片已完整显示，1.5 秒画面保持稳定且无长时间空白。
  3. 上述数据不等同于首次注册冷路径；仍需清除测试 App 数据后重新注册复测。
  4. 清除并重装优化版后完成首次注册连续采样：注册页开始收起键盘后的下一采样帧（间隔约 0.2 秒）已出现完整首页结构和可交互导航，未出现路由空白。
  5. 同次采样中远程 Unsplash 封面在首页出现后的约 15 秒内均未显示，确认剩余等待来自远程图片链路，而不是路由或首页同步计算。
  6. 第二轮优化版覆盖安装后真机启动，0.5 秒采样中已加载封面正常显示，未完成的远程封面立即显示本地 `STILL PHOTO` 占位；页面无整块黑屏，顶部频道、卡片信息和底部导航均可直接操作。
- 建议排查：
  1. 增加注册提交、路由完成、首页挂载、首批数据完成和首屏图片完成的性能时间点。
  2. 检查是否存在串行数据请求、固定延时、重复初始化或同步大数据排序。
  3. 首屏优先渲染骨架和首批内容，其余图片与内容延迟加载。
  4. 为 Mock 数据和已加载图片增加会话内缓存，避免注册跳转后重复构建。
- 验证标准：记录优化前后真机耗时；加载过程始终有明确视觉反馈，且重复进入首页不发生同等长度等待。
