# PP 品牌命名与图标设计初步方案

## 项目名称

PP 项目的 App 主品牌暂定为：

```text
Still
```

海外区副标题：

```text
Keep your presence in frame.
```

中国区副标题：

```text
留住此刻的样子
```

Still 的定位不是普通约拍、陪拍或写真工具，而是一个生活方式影像记忆平台。它负责把用户在某个城市、场景、阶段和状态里的样子认真记录下来。

## 与帧遇科技的关系

公司名“帧遇科技”表达的是某个人、某个场景、某束光被一帧遇见。

Still 表达的是这一帧被留下后的状态：生活原本是流动的，Still 把值得记住的一刻安静地保存下来。

因此，Still 不需要在字面上包含“帧”，但它在精神上与“帧遇”对应：

```text
帧遇：一帧被遇见
Still：这一帧被留下
```

## 与 LT / Vibe 的呼应

LT 项目的 App 主品牌暂定为 Vibe，副标题方向是“找到适合生活的样子”。

两个 App 的关系是：

```text
Vibe：找到样子
Still：留住样子
```

Vibe 负责帮助用户找到适合自己生活、衣橱、场景和状态的样子；Still 负责把这个样子放进真实世界，通过摄影、地点、姿态、光线和作品交付沉淀为影像记忆。

更完整的闭环是：

```text
场景 -> 造型 -> 商品/衣橱 -> 拍摄 -> 影像记忆
```

## 总体品牌宇宙

两个项目共享的底层母题是：

```text
Presence
```

Presence 不一定作为用户可见品牌名，它代表一个人在场景里的状态、气质、出现方式和被看见的感觉。

Vibe 让用户找到适合生活的 presence；Still 把这个 presence 留下来。

对外可以表达为：

```text
Vibe helps you find the looks that fit your life.
Still keeps those moments in frame.
```

中文表达：

```text
Vibe 找到适合生活的样子。
Still 留住此刻的样子。
```

## 图标设计方向

Still 图标的关键词是：

- 静止；
- 画面边界；
- 影像记忆；
- 城市；
- 一点被留下的光；
- 克制、高级、安静。

初步视觉方向：

- 深墨黑、胶片黑或冷灰背景；
- 极简画面框或取景框，但不要使用传统相机镜头；
- 框内保留一个小光点、抽象人影或城市水平线，暗示“此刻被留下”；
- 可以轻微暗示 stillness，但不要做明显播放器暂停按钮；
- 整体气质应像生活方式影像品牌，不像摄影接单平台。

与 Vibe 图标的统一母题是一枚光点：

```text
Vibe：光正在形成，代表状态被找到。
Still：光被放进画面，代表此刻被留下。
```

## App Store 本地化策略

中国区建议使用英文主名加中文副标题：

```text
Still
留住此刻的样子
```

海外区：

```text
Still
Keep your presence in frame
```

主品牌不使用“约拍、陪拍、写真”等功能词，避免降低生活方式品牌感。这些词可以放入关键词、描述或搜索优化中，而不是放进主品牌。
