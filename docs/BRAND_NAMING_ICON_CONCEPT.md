# Still 品牌命名与图标定稿

## 项目名称

PP 项目的核心品牌为：

```text
Still
```

简体中文市场名称：

```text
Still帧遇
```

默认及海外英文名称：

```text
Still
```

海外英文副标题：

```text
Keep your presence in frame
```

简体中文副标题：

```text
发现摄影师，留住旅行与日常
```

Still 的定位不是普通约拍、陪拍或写真工具，而是一个生活方式影像记忆平台。它负责把用户在某个城市、场景、阶段和状态里的样子认真记录下来。

## 与帧遇科技的关系

公司名“帧遇科技”表达的是某个人、某个场景、某束光被一帧遇见。

Still 表达的是这一帧被留下后的状态：生活原本是流动的，Still 把值得记住的一刻安静地保存下来。

因此，海外名称保持简洁的 `Still`，简体中文名称使用 `Still帧遇`，把核心品牌与公司语义连接起来：

```text
帧遇：一帧被遇见
Still：这一帧被留下
```

## 与 LT / Vibe 的呼应

LT 项目的 App 主品牌暂定为 Vibe，副标题方向是“找到适合生活的样子”。

两个 App 的关系是：

```text
Vibe：找到样子
Still：留住样子
```

Vibe 负责帮助用户找到适合自己生活、衣橱、场景和状态的样子；Still 负责把这个样子放进真实世界，通过摄影、地点、姿态、光线和作品交付沉淀为影像记忆。

更完整的闭环是：

```text
场景 -> 造型 -> 商品/衣橱 -> 拍摄 -> 影像记忆
```

## 总体品牌宇宙

两个项目共享的底层母题是：

```text
Presence
```

Presence 不一定作为用户可见品牌名，它代表一个人在场景里的状态、气质、出现方式和被看见的感觉。

Vibe 让用户找到适合生活的 presence；Still 把这个 presence 留下来。

对外可以表达为：

```text
Vibe helps you find the looks that fit your life.
Still keeps those moments in frame.
```

中文表达：

```text
Vibe 找到适合生活的样子。
Still 留住此刻的样子。
```

## 图标设计定稿

Still 图标由三项固定元素组成：

- 连续、可辨认的抽象 `S`，通过曲率和宽窄变化保留人的姿态感；
- 青色硬边闪光投影，让主体成为被闪光灯照亮的视觉中心；
- 黄色相机对焦角，表达摄影功能，但不把图标做成相机工具图。

固定配色：

- 背景柿橙：`#FF7043`
- 主体深海军蓝：`#142A4C`
- 闪光硬影青色：`#6FAEB6`
- 对焦框黄色：`#FFD23F`

图标禁止增加独立头部、肢体、道路透视、负形人物、文字或中文角标。源文件为 `brand/still-app-icon-1024.png`，SHA-256 为 `921777E064A6210E1C03BA5CCE0F57DC74C8A7D696710D3596A7FCAF3D537426`。

图标保持 1024 x 1024、sRGB、无透明通道和无预制圆角，由系统应用圆角蒙版。

## App Store 本地化策略

App Store Connect 使用同一个 App 记录和 Bundle ID `com.frameyu.still`，按语言维护名称。

简体中文：

```text
名称：Still帧遇
副标题：发现摄影师，留住旅行与日常
```

英文及默认语言：

```text
名称：Still
副标题：Keep your presence in frame
```

本地化按用户语言生效，不按设备物理位置强制切换。简体中文桌面名称由 iOS `InfoPlist.strings` 提供，默认桌面名称保持 `Still`。

对外不得把 `Still帧遇` 简称为“帧遇”，以降低与现有同类 App 的混淆风险。App Store Connect 名称占用、APP 备案逐字一致和商标近似检索仍是正式发布门槛。

主品牌不使用“约拍、陪拍、写真”等功能词，避免降低生活方式品牌感。这些词可以放入关键词、描述或搜索优化中，而不是放进主品牌。
